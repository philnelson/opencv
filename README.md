# OpenCV: Open Source Computer Vision Library

OpenCV is the world's biggest computer vision library, providing over 2,500 algorithms and helper functions for efficiently manipulating image and video data. Many core functions make use of hardware acceleration on supported platforms. The [opencv_contrib](https://github.com/opencv/opencv_contrib) repository contains additional tools and functions not suitable for the core library due to being legacy code, experimental, too "heavy" on dependencies, being differently-licensed (LGPL, etc), and other Reasons.

OpenCV provides stable [python](https://github.com/opencv/opencv-python) and [C++](https://github.com/opencv/opencv) APIs as well as [release packages](https://opencv.org/releases/) for Windows, Android, and iOS. The library was founded in June 2000 and is operated by the non-profit Open Source Vision Foundation.

OpenCV is a 501(c)(3) registered non-profit in the United States of America.

OpenCV operates a [membership program](https://opencv.org/membership/) for organizations who depend upon and wish to support the library with a financial contribution or development resources. The support of these organizations ensures the continued development and security of the OpenCV library.

OpenCV also accepts [donations from individuals](https://opencv.org/support/) and is listed on the [Benevity Causes portal](https://causes.benevity.org/causes/840-455202940). If you work for a larger organization, it's possible that your employer will match your donations, effectively doubling your support! Ask your boss about it.

Current OpenCV Member organizations in good standing are listed on [the OpenCV Homepage](https://opencv.org).

## Contributing Code

*Please* read the [contribution guidelines](https://github.com/opencv/opencv/wiki/How_to_contribute) before starting work on a pull request.

Check the "[community help requested](https://github.com/opencv/opencv/issues?q=is%3Aissue%20state%3Aopen%20label%3A%22community%20help%20requested%22)" label on the GitHub Issue Tracker to find issues the core team is looking for assistance on.

### Contribution Quick Start

* Follow the [coding style guide](https://github.com/opencv/opencv/wiki/Coding_Style_Guide)
* Use one [pull request](https://github.com/opencv/opencv/pulls) per issue
* Choose the right base [branch](https://github.com/opencv/opencv/branches)
* Include tests and documentation
* Clean up "oops" commits before submitting
